Servidor de envio

Com Gmail, use uma senha de app, nunca a senha da conta. Ela é criada em Conta Google →︎ Segurança →︎ Senhas de app, e só aparece uma vez. Host smtp.gmail.com, porta 587.

Teste de e-mail

Manda uma mensagem real, no template padrão, para o endereço que você informar. É a forma honesta de saber se o SMTP responde: se chegar, funciona de verdade.

Limites e boa vizinhança

Conta Gmail comum entrega até 500 e-mails por dia.
